# TODO-лист — учебная вёрстка

Откройте index.html двойным щелчком — установка программ и запуск сервера не нужны.

В основе — блок statuses (To-Do / Done) из макета занятия:
https://www.figma.com/design/lFgiQPXwy6mKjIUcTKFSdj/Untitled?node-id=0-1

Это упрощённая вёрстка, а не точная копия: сохранены две колонки, цвета,
светлые карточки, тексты задач и даты. Отметки приоритета сделаны текстом.
На узком экране колонки располагаются друг под другом.

- index.html — заголовки, колонки и карточки.
- style.css — цвета, размеры, отступы и расположение элементов.

JavaScript не используется. Добавления, удаления и переноса задач нет:
задание посвящено внешнему виду страницы.
